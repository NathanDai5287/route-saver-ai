# route-saver-ai

AI route planner idea I started building over the weekend. It mostly uses fake data right now.

The home page works, but none of the buttons do anything yet. The route generator is still a placeholder.

## local setup

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
